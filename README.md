## 구조

```
.
├─ index.html            # 전체 마크업 (한국어 본문)
├─ css/
│  ├─ reset.css          # 최소 리셋
│  ├─ tokens.css         # 디자인 토큰 (색·타이포·간격) + 다크 테마
│  └─ style.css          # 레이아웃 및 컴포넌트
├─ js/
│  ├─ i18n.js            # 한/영 전환
│  ├─ theme.js           # 라이트/다크 전환
│  └─ main.js            # 헤더·모바일 메뉴·스크롤·이메일 복사
└─ assets/img/           # 프로필 사진, 프로젝트 스크린샷
```

## 로컬에서 보기

`index.html`을 브라우저로 바로 열어도 되지만, 이메일 복사 버튼(Clipboard API)은
보안 컨텍스트에서만 동작하므로 아래처럼 서버로 띄우는 편이 정확합니다.

```bash
npx serve .
# http://localhost:3000
```

## 구현 메모

- **디자인 토큰** — 색·간격·타이포를 `css/tokens.css`의 커스텀 프로퍼티로 관리합니다.
  사이트 전체 톤은 `--accent` 한 줄로 바뀝니다.
- **다크 모드** — `<head>`의 인라인 스크립트가 첫 페인트 전에 테마를 확정해 새로고침 시
  깜빡임(FOUC)이 없습니다. 사용자가 직접 고른 적이 없으면 OS 설정을 따라갑니다.
- **한/영 전환** — HTML에는 한국어를 그대로 두어 JS 없이도 본문이 읽히고 검색엔진이
  수집할 수 있게 했습니다. `js/i18n.js`에는 영어 사전만 두고, 한국어로 돌아갈 때는
  최초 로드 시 떠 둔 스냅샷을 복원합니다.
- **IntersectionObserver** — 섹션 등장 애니메이션과 내비게이션 scroll spy 두 곳에
  같은 방식으로 사용했습니다. 스크롤 이벤트 리스너를 쓰지 않아 부담이 적습니다.
- **접근성** — 시맨틱 마크업, 본문 바로가기 링크, 키보드 전용 탐색, 모바일 메뉴
  포커스 관리, `aria-live` 상태 알림, `prefers-reduced-motion` 대응을 넣었습니다.
